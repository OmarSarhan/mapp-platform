Advanced workspace configuration

These are optional XYZ capabilities. Empty JSON means the capability has not been configured; it is not a dashboard or API error.

Where each setting belongs

  • Workspace templates are named definitions under top-level templates. Locale and layer template or templates entries refer to them.
  • Dictionaries use keyvalue_dictionary in Advanced locale JSON, or in Advanced layer JSON when the replacement is layer-specific.
  • Bundled plugins are configured with their documented locale property. Check the connected server’s plugin catalogue before adding one.
  • Gazetteer search is a layer.gazetteer setting in Advanced layer JSON, not a locale setting.

Safe setup workflow

  1. Inspect the exact supported shape in the connected server schema.
  2. Add the smallest configuration needed and validate it.
  3. Save through the dashboard, or create and review a revision-bound CLI proposal.
  4. After reload, verify the affected map behavior. Template descriptors are checked on save but fetched by XYZ only when used.

CLI equivalents

config-cli schema --pointer '/$defs/templateDefinition'
config-cli schema --pointer '/$defs/locale/properties'
config-cli schema --pointer '/$defs/layer/properties/gazetteer'
config-cli plugins list
config-cli plugins usage PLUGIN_KEY
config-cli workspace get
config-cli layers get "LAYER KEY"

Use config-cli proposals check to validate a focused JSON Pointer change before creating a proposal. Do not directly replace the workspace document.
